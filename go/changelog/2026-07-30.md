## 版本号：V-2.0.0-final

### ✨ 新增功能
- [+] **Go 版本新增 Litematic 格式支持**：和 Python 版本一样，现在 Go 版本也支持输出 `.litematic` 格式文件
- [+] **Web 版本新增 URL 快速转换**：支持直接粘贴图片 URL 链接进行快速转换
- [+] **Web 版本新增转换统计信息展示**：转换完成后显示结构尺寸、总方块数、方块类型数、转换耗时等统计信息
- [+] **Web 版本新增最终版本主题**：采用紫色渐变主题，展示最终版本公告横幅

### 🔧 改进
- [~] **Web 版本重构为纯 Vue 3 前端**：去除商店、分享圈、朋友圈、用户登录等功能，精简核心体验
- [~] **精简 Web 后端 API**：仅保留核心图片转换相关接口，提升性能和稳定性
- [~] **Python CLI 版本**：删除时间炸弹检查机制，优化资源监控模块
- [~] **Go 版本**：修复 package 冲突问题，确保构建正常
- [~] **修复 GitHub Actions 工作流构建问题**：删除 SMTP 邮件通知代码，优化工作流配置
- [~] **完善各版本目录结构**：修复缺失文件，确保版本一致性

### 🌐 版本信息
- **CLI 版本 (Python)**: 功能完整，支持 `.schem` / `.json` / `.litematic` / `.bdx` / `.mcfunction` / `.mcstructure` / `.mcworld` 等多种格式
- **Web 版本 (Python + Flask)**: 基于 Vue 3 的现代化 Web 界面，支持文件上传和 URL 快速转换
- **Go 版本**: 高性能 Go 语言实现，支持 `.schem` / `.json` / `.litematic` 格式
